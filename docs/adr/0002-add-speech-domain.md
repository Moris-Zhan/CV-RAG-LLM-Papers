# 新增 Speech 領域收錄語音論文

在原本的 `CV／RAG／LLM` 之外新增第四個領域 `Speech`，收錄以語音訊號為輸入，或以語音處理為核心的論文（例如 AISHELL-4 會議語音資料集、ASCEND 中英語碼轉換資料集）。判斷順序改為 CV → Speech → RAG → LLM。原因是這兩篇語音資料集論文放在既有三個領域都不合適：沒有影像輸入，與檢索無關，主要貢獻也不是 LLM；如果硬塞進 LLM，「LLM」這個領域名稱就失去意義，之後找語音論文也找不到。

此決策延續 [0001](0001-domain-first-single-home-with-tags.md) 的原則：每篇論文只屬於一個領域，跨領域主題用標籤表示。這裡只擴充領域的值。

## Considered Options

- **歸入 LLM**：不需要新資料夾，但違反「主要貢獻」的判斷；ASCEND 的基線是 wav2vec 2.0，與 LLM 無關。
- **新增 `Speech` 標籤，論文仍放在 LLM**：標籤用於跨領域主題，語音是模態，不是研究主題；資料夾位置仍然錯誤。
- **新增 `Speech` 領域（採用）**：新增一個第一層資料夾，並更新 README 的分類規則與 GLOSSARY。

## Consequences

- repo 名稱 `CV-RAG-LLM-Papers` 不再列出所有領域；目前不改名，以免連結失效。
- 同時涉及語音與影像的論文（例如影音模型）依判斷順序歸在 CV；若這類論文變多，應另立 ADR 重新檢討。
- 新增領域時，要同步更新 README 的目錄結構、分類規則與 GLOSSARY 的「領域」定義。
