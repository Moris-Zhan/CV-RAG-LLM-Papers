# 論文依領域單一歸屬，跨領域主題改用標籤

論文以 `CV／RAG／LLM` 三個領域作為第一層資料夾，每篇論文依「主要貢獻」只放在一個領域（影像輸入或評測 VLM → CV；檢索器、檢索來源或 RAG 流程為核心 → RAG；其餘 → LLM），跨領域的研究主題（例如 MCQ-Benchmark、Distractor-Gen）只以標籤記錄在 README 索引。這樣做是因為三個領域與 repo 名稱一致、長期穩定，而研究主題會隨閱讀方向改變；用標籤表示主題，新增或調整主題時不需要搬動檔案，也避免同一篇論文在多個資料夾重複。

## Considered Options

- **依研究主題建資料夾**（如 `Benchmark-Eval/`、`Retrieval/`）：目前 7 篇論文中有 5 篇同時屬於多個主題，主題資料夾會頻繁重組。
- **領域／主題兩層資料夾**：路徑變長，且同一篇論文仍需在多個主題間擇一，只是把問題往下移一層。
- **允許一篇論文放在多個領域**：需要複製檔案或使用連結，兩份副本容易不同步。

## Consequences

- 要改變分類方式，必須搬動所有論文資料夾並更新 README 索引，成本高；調整前應先新增 ADR。
- 判斷領域時只看主要貢獻，例如 AutoMCQA 同時是 MCQ 基準，但核心貢獻在比較檢索來源，因此歸在 RAG。
