# 以「取車照 vs 還車照」比對判定新車損

題目要求辨識「因本次租車產生的新車損」，單張還車照偵測只能看出「有損傷」，無法分辨是不是舊傷，也就無法歸責，正是客訴與人工複查的來源。我們決定以同一視角的取車照作為參考，對齊後做變化偵測，只對新增損傷發出異常預警；方案架構、即時防呆（必須拍到可比對的固定視角）與簡報敘事都以此為核心。

## Considered Options

- 單張還車照車損偵測：實作最簡單，但無法歸責，且舊傷會反覆觸發預警。
- 取車照 vs 還車照變化偵測（採用）：需要視角一致的照片，因此即時防呆必須保證視角正確，兩個環節互相依賴。

## Consequences

- 環節一的視角分類從「加分」變成「必要條件」。
- 產業案例（Hertz × UVeye 自動比對並直接收費引發爭議）提醒：比對結果達收費等級時，須經人工確認並提供證據與申訴流程。
