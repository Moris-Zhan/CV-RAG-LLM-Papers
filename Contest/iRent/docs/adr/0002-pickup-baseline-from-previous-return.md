# 以上一位用戶的還車照加簽名前異常照作為取車基準

iRent 官方取車流程只要求用戶在簽名與確認取車之前「將車輛異常狀況拍照上傳」，不會拍完整取車照，所以 ADR 0001 的「取車照 vs 還車照」比對常缺少基準。媒體報導顯示 iRent 現行實務已以「前一位消費者的照片」判斷車損歸屬。我們決定以**上一位用戶的還車照，加上本次用戶在簽名前上傳的異常照片**作為取車基準，把現行人工歸責正式化並自動化，同時不增加官方流程的拍照負擔。

## Considered Options

- 要求每位用戶取車時拍完整一組照片：基準最完整，但取車變慢，與官方「只拍異常」的流程衝突。
- 只用本次用戶的取車異常照：維持現況，但沒拍到的部位無法比對，新車損仍無法歸責。
- 上一位還車照＋簽名前異常照（採用）：沿用現有資料與現有入口（車況檢視、車況回報），用戶只需確認 AI 挑出的 2–3 張差異照。

## Consequences

- 還車照品質變成下一位用戶的權益，所以環節一的即時防呆在還車時更重要。
- 上一位還車照缺漏或不合格的視角標為「無基準」，該視角差異不自動歸責本次用戶，交人工判斷（DECISIONS D6a）。
- 本次用戶在簽名前回報的差異歸為「停放期間損傷」，由營運處理（D6b）；這同時成為車況接力點數的發放條件。
- 本 ADR 補充 ADR 0001：比對對象由「取車照」改為「取車基準」。
